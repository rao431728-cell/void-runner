# VOID//RUNNER

VOID//RUNNER is a browser-based arcade survival game. The player pilots the last light through escalating enemy waves, evolves weapons during the run and confronts the Singularity after three minutes.

## Features

- Canvas-rendered arena, particles and combat effects
- Keyboard, pointer and touch controls
- Dash movement with cooldown and invulnerability timing
- Auto-fire, enemy archetypes, hazards and boss fight
- Randomized upgrade choices and build progression
- Web Audio sound effects and procedural music
- Local high-score persistence
- Pause, restart, fullscreen and accessibility controls
- Automated gameplay smoke test

## Technology

- JavaScript
- HTML Canvas API
- Web Audio API
- HTML and CSS
- localStorage
- Optional WebMCP controls

## Run locally

Serve the `dist` directory with a static web server and open `index.html`.

## Verification

The automated smoke test covers menu rendering, starting, auto-fire, dash immunity, pause/resume, upgrades, a three-minute simulation, boss victory, death, restart and return to the hangar.

AI coding assistance was used during development. Requirements, acceptance decisions, testing and publication review remained under human control.
